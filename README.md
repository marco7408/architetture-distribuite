# Architetture dei Sistemi Distribuiti

Sito web vetrina sulle architetture dei sistemi distribuiti.

**Autori:** Marco Rollo, Daniel Allen Greer, Mirko Greco Ruben

## Descrizione

Il progetto presenta i principali concetti sui sistemi distribuiti:
- Introduzione ai sistemi distribuiti
- Classificazione di Flynn
- Cluster e Grid Computing
- Sistemi pervasivi
- Architetture software
- Middleware

Include anche il PDF: `Architetture_dei_Sistemi_Distribuiti.pdf`
